# WoW Play Harness MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude Code logs a human character into a WoW 1.18.1 client on the gameserver TortoiseBots server, hires 2 bots, kills one mob, and gets back the parsed combat log plus a "what the bots did" summary.

**Architecture:** A Python package `wowharness` runs on Windows (`python.exe` from a Windows venv), started by Claude Code in WSL as a stdio MCP server. It drives the WoW window by handle with `PostMessage`, reads `Logs\WoWCombatLog.txt` / `Logs\WoWChatLog.txt` by byte offset, talks SOAP to the server, and a tiny 1.12 addon prints `HX|` state lines into chat. Pure logic (parsing, tailing, key encoding, reports) is tested on Linux with pytest; Win32 and SOAP sit behind small classes that tests replace with fakes.

**Tech Stack:** Python 3.11+ (Windows and Linux), `mcp` (FastMCP), `pywin32`, `Pillow`, `requests`, `pytest`; Lua 5.0 (WoW 1.12 addon API).

**Spec:** `docs/specs/2026-10-11-wow-play-harness-design.md`

## Global Constraints

- Game exe is `WoW.exe`; never start `TurtleWoW.exe` (installer) or `turtle-wow.exe` (launcher).
- Client: `C:\Users\<you>\Clients\1.18.1-7272-Hotfix-2026-04-12`.
- `Config.wtf` must hold `SET gxWindow "1"` and `SET movie "0"`; never send ESC before the world is loaded.
- Login screen: click the account box and the password box; never TAB between them.
- Input goes to the WoW window by HWND with `PostMessage`; never `SendInput`, never to the focused window.
- Before every action and capture: the client process is alive and its window exists; otherwise answer `client not running (exit code N)`.
- Server: `game-server`, Tailscale `192.0.2.10` (ssh alias `gameserver`), auth 3724, SOAP 7878.
- Account: the human account the Yu'lon install creates (`player`); never a bot account.
- Code is edited in `~/wow-play-harness` (Linux) and synced to `C:\Users\<you>\wow-play-harness`; the Windows venv lives at `C:\Users\<you>\.wowharness-venv` (outside the sync target).
- Nothing is reported as tested in game unless it ran in game; evidence goes under `docs/evidence/`.
- Secrets (account password, SOAP password) live only in `C:\Users\<you>\.wowharness.json`, never in the repo.

## Review Focus

1. **Text with characters chat treats specially** (`|`, `"`, `\`, non-ASCII like `ø`): `chat()` must send them literally or refuse; a person expects `/script print("a|b")` to arrive as typed. → test in Task 3 (`test_encode_text_*`).
2. **Log file truncated or recreated between tails** (client restarted, `/combatlog` toggled): `tail()` must restart from 0 and say so, never return garbage or crash. → test in Task 2 (`test_tail_after_truncate`).
3. **Combat-log line the parser does not know**: kept as `kind="other"` with the raw text, never dropped, so the report still shows it. → test in Task 4 (`test_unknown_line_kept`).
4. **Names with spaces and apostrophes** (`Kobold Vermin`, `Mor'Ladim`, spell `Shadow Word: Pain`): the parser must split source/spell/target right. → test in Task 4 (`test_names_with_spaces_and_apostrophes`).
5. **The client dies mid-action** (crash, closed by hand): the next tool call answers `client not running`, not a timeout or empty string. → test in Task 3 (`test_dead_client_answers_not_running`).

```python
    found = []
    def cb(h, _):
        if win32gui.IsWindowVisible(h) and win32process.GetWindowThreadProcessId(h)[1] == pid:
```

```python
# wowharness/logs.py
"""New lines of a growing log file, by byte offset. A file shorter than the offset was truncated or recreated: read it from 0."""
import os


class LogTail:
    def __init__(self, path: str):
        self.path = path

    def size(self) -> int:
        try:
            return os.path.getsize(self.path)
        except OSError:
            return 0

    def read_since(self, offset: int) -> tuple[list[str], int, bool]:
        size = self.size()
        if size == 0 and not os.path.exists(self.path):
            return [], 0, False
        restarted = size < offset
        start = 0 if restarted else offset
        with open(self.path, "rb") as f:
            f.seek(start)
            data = f.read()
        end = data.rfind(b"\n")
        if end < 0:
            return [], start, restarted
        chunk = data[: end + 1]
        try:
            text = chunk.decode("utf-8")
        except UnicodeDecodeError:
            text = chunk.decode("latin-1")
        lines = [l.rstrip("\r") for l in text.split("\n")[:-1]]
        return lines, start + end + 1, restarted
```

```python
# wowharness/keys.py
"""Pure key encoding: names to virtual-key codes, text to WM_CHAR codes, lParam bits."""

VK = {
    "enter": 0x0D, "escape": 0x1B, "space": 0x20, "tab": 0x09, "backspace": 0x08,
    "left": 0x25, "up": 0x26, "right": 0x27, "down": 0x28,
    **{c: ord(c.upper()) for c in "abcdefghijklmnopqrstuvwxyz"},
    **{str(d): 0x30 + d for d in range(10)},
    **{f"f{n}": 0x6F + n for n in range(1, 13)},
}


def encode_text(s: str) -> list[int]:
    out: list[int] = []
    for ch in s:
        code = ord(ch)
        if code > 0xFFFF:
            raise ValueError(f"character {ch!r} cannot be typed into WoW chat")
        out.append(code)
        if ch == "|":
            out.append(code)  # WoW chat reads one | as an escape; || is a literal bar
    return out


def key_lparam(vk: int, scan: int, up: bool) -> int:
    lp = 1 | (scan << 16)
    return lp | (0xC0 << 24) if up else lp
```

```python
# wowharness/window.py
"""The WoW window by handle. Imports Win32 lazily so the package loads on Linux for tests."""
import ctypes
import subprocess
import time

from .keys import key_lparam


class Window:
    def __init__(self, proc: subprocess.Popen, hwnd: int):
        self.proc, self.hwnd = proc, hwnd

    @classmethod
    def launch(cls, exe: str, cwd: str, timeout_s: float = 60) -> "Window":
        import win32gui, win32process
        proc = subprocess.Popen([exe], cwd=cwd)
        deadline = time.time() + timeout_s
        while time.time() < deadline:
            found: list[int] = []
            def cb(h, _):
                if win32gui.IsWindowVisible(h) and win32process.GetWindowThreadProcessId(h)[1] == proc.pid:
                    found.append(h)
            win32gui.EnumWindows(cb, None)
            if found:
                return cls(proc, found[0])
            if proc.poll() is not None:
                break
            time.sleep(0.5)
        raise RuntimeError(f"WoW.exe window did not appear (exit code {proc.poll()})")

    def alive(self) -> bool:
        import win32gui
        return self.proc.poll() is None and bool(win32gui.IsWindow(self.hwnd))

    def exit_code(self) -> int | None:
        return self.proc.poll()

    def _restore_if_minimised(self) -> None:
        import win32con, win32gui
        if win32gui.IsIconic(self.hwnd):
            win32gui.ShowWindow(self.hwnd, win32con.SW_SHOWNOACTIVATE)

    def post_key(self, vk: int, down: bool) -> None:
        import win32con, win32gui
        self._restore_if_minimised()
        scan = ctypes.windll.user32.MapVirtualKeyW(vk, 0)
        msg = win32con.WM_KEYDOWN if down else win32con.WM_KEYUP
        win32gui.PostMessage(self.hwnd, msg, vk, key_lparam(vk, scan, up=not down))

    def post_char(self, code: int) -> None:
        import win32con, win32gui
```

```python
# wowharness/client.py
"""The game client: Config.wtf, launch, chat/lua/keys by handle, login, waits on the chat log."""
import os
import re
import time
from typing import Callable

from .config import Config
from .keys import VK, encode_text
from .logs import LogTail

WTF_KEYS = {"gxWindow": "1", "movie": "0"}


class ClientNotRunning(Exception):
    pass


class Client:
    def __init__(self, cfg: Config, window_factory: Callable[[], object]):
        self.cfg, self.window_factory, self.window = cfg, window_factory, None
        self.chat_log = LogTail(os.path.join(cfg.client_dir, "Logs", "WoWChatLog.txt"))
        self.combat_log = LogTail(os.path.join(cfg.client_dir, "Logs", "WoWCombatLog.txt"))
        self._sleep = time.sleep

    def _check(self):
        if self.window is None:
            raise ClientNotRunning("client not running (exit code None)")
        if not self.window.alive():
            raise ClientNotRunning(f"client not running (exit code {self.window.exit_code()})")
        return self.window

    def ensure_config_wtf(self) -> None:
        path = os.path.join(self.cfg.client_dir, "WTF", "Config.wtf")
        lines = open(path, encoding="utf-8").read().splitlines() if os.path.exists(path) else []
        want = {**WTF_KEYS, "realmlist": self.cfg.server_host}
        kept = [l for l in lines if not any(re.match(rf'SET {k} ', l, re.I) for k in want)]
        kept += [f'SET {k} "{v}"' for k, v in want.items()]
        with open(path, "w", encoding="utf-8", newline="\r\n") as f:
            f.write("\n".join(kept) + "\n")

    def launch(self) -> dict:
        self.ensure_config_wtf()
        self.window = self.window_factory()
        return {"pid": self.window.proc.pid, "hwnd": self.window.hwnd}

    def _tap(self, vk: int) -> None:
        w = self._check()
        w.post_key(vk, True); self._sleep(0.03); w.post_key(vk, False)

    def chat(self, text: str) -> None:
        codes = encode_text(text)
        w = self._check()
        self._tap(VK["enter"])
        self._sleep(0.1)
        for c in codes:
            w.post_char(c); self._sleep(0.01)
        self._tap(VK["enter"])

    def run_lua(self, code: str) -> None:
        self.chat("/script " + code)

    def key(self, name: str, hold_ms: int = 0) -> None:
        w = self._check()
        vk = VK[name.lower()]
        w.post_key(vk, True); self._sleep(max(hold_ms, 30) / 1000); w.post_key(vk, False)

    def chat_offset(self) -> int:
        return self.chat_log.size()

    def combat_offset(self) -> int:
        return self.combat_log.size()

    def wait_chat(self, pattern: str, since: int, timeout_s: float) -> str | None:
        rx, offset, deadline = re.compile(pattern), since, time.time() + timeout_s
        while time.time() < deadline:
            self._check()
            lines, offset, _ = self.chat_log.read_since(offset)
            for line in lines:
                if rx.search(line):
                    return line
            self._sleep(0.5)
        return None

    def login(self, account: str, password: str, char_index: int = 0, timeout_s: float = 90) -> dict:
        w = self._check()
        self._sleep(5)  # login screen settles; never ESC here (it quits during the intro)
        w.click(*self.cfg.login_account_xy)
        for c in encode_text(account): w.post_char(c)
        w.click(*self.cfg.login_password_xy)
        for c in encode_text(password): w.post_char(c)
        self._tap(VK["enter"])
        self._sleep(10)  # realm handshake to character select
        for _ in range(char_index):
            self._tap(VK["down"])
        self._tap(VK["enter"])
        self._sleep(15)  # loading screen
        since = self.chat_offset()
        self.chat("/chatlog")
        self.chat("/combatlog")
        self.run_lua("HX_Ready()")
        line = self.wait_chat(r"HX\|ready", since, timeout_s)
        if line is None:
            return {"ok": False, "reason": "no HX|ready in WoWChatLog.txt (chat log not live, addon missing, or not in world)"}
        return {"ok": True, "line": line}
```

```python
# wowharness/combat.py
"""1.12 combat-log text to events. Patterns follow the client's GlobalStrings; an unknown line is kept as kind 'other'."""
import re
from dataclasses import dataclass

TIME = re.compile(r"^(\d+/\d+ \d+:\d+:\d+\.\d+)\s{2}(.*)$")
N = r"(.+?)"  # a name: lazy, may hold spaces and apostrophes

PATTERNS: list[tuple[str, re.Pattern]] = [
    ("slain", re.compile(rf"^You have slain {N}!$")),
    ("heal", re.compile(rf"^{N}'s {N} (critically )?heals {N} for (\d+)\.$")),
    ("heal", re.compile(rf"^Your() {N} (critically )?heals {N} for (\d+)\.$")),
    ("spell", re.compile(rf"^{N}'s {N} (hits|crits) {N} for (\d+)(?: \w+ damage)?\.$")),
    ("spell", re.compile(rf"^Your() {N} (hits|crits) {N} for (\d+)(?: \w+ damage)?\.$")),
    ("cast_start", re.compile(rf"^{N} begins? to cast {N}\.$")),
    ("cast", re.compile(rf"^{N} casts? {N} on {N}\.$")),
    ("gain", re.compile(rf"^{N} gains? {N}\.$")),
    ("dies", re.compile(rf"^{N} dies\.$")),
    ("melee", re.compile(rf"^{N} (hits?|crits?) {N} for (\d+)\.$")),
]


@dataclass(frozen=True)
class Event:
    time: str
    kind: str
    source: str
    spell: str | None
    target: str | None
    amount: int | None
    crit: bool
    raw: str


def _who(name: str, me: str) -> str:
    return me if name in ("You", "you", "") else name


def parse_line(line: str, me: str) -> Event:
    m = TIME.match(line)
    t, body = (m.group(1), m.group(2)) if m else ("", line)
    for kind, rx in PATTERNS:
        g = rx.match(body)
        if not g:
            continue
        x = g.groups()
        if kind == "slain":
            return Event(t, kind, me, None, x[0], None, False, line)
        if kind == "heal":
            return Event(t, kind, _who(x[0], me), x[1], _who(x[3], me), int(x[4]), bool(x[2]), line)
        if kind == "spell":
            return Event(t, kind, _who(x[0], me), x[1], _who(x[3], me), int(x[4]), x[2] == "crits", line)
        if kind == "cast_start":
            return Event(t, kind, _who(x[0], me), x[1], None, None, False, line)
        if kind == "cast":
            return Event(t, kind, _who(x[0], me), x[1], _who(x[2], me), None, False, line)
        if kind == "gain":
            return Event(t, kind, _who(x[0], me), x[1], None, None, False, line)
        if kind == "dies":
            return Event(t, kind, x[0], None, None, None, False, line)
        if kind == "melee":
            return Event(t, kind, _who(x[0], me), None, _who(x[2], me), int(x[3]), x[1].startswith("crit"), line)
    return Event(t, "other", "", None, None, None, False, line)


def parse_lines(lines, me: str) -> list[Event]:
    return [parse_line(l, me) for l in lines if l.strip() and not l.startswith("#")]
```

```python
# wowharness/report.py
"""Per-actor fight totals and a short 'what the bots did' text."""
from collections import defaultdict

from .combat import Event


def _actor() -> dict:
    return {"damage_done": 0, "damage_taken": 0, "healing_done": 0, "casts": {}, "deaths": 0}


def build(events: list[Event], chat_lines: list[str], me: str, party: list[str]) -> dict:
    actors: dict[str, dict] = defaultdict(_actor)
    for name in [me, *party]:
        actors[name]
    killed, unknown = [], 0
    for e in events:
        if e.kind in ("melee", "spell") and e.amount is not None:
            actors[e.source]["damage_done"] += e.amount
            if e.target:
                actors[e.target]["damage_taken"] += e.amount
        if e.kind in ("spell", "heal", "cast") and e.spell:
            casts = actors[e.source]["casts"]
            casts[e.spell] = casts.get(e.spell, 0) + 1
        if e.kind == "heal" and e.amount is not None:
            actors[e.source]["healing_done"] += e.amount
        if e.kind == "dies":
            actors[e.source]["deaths"] += 1
            if e.source not in party and e.source != me:
                killed.append(e.source)
        if e.kind == "other":
            unknown += 1
    # Chat-log lines carry a time prefix, so a party member's name anywhere in the line counts.
    bot_lines = [l for l in chat_lines if "TBM:" in l or any(p in l for p in party)]
    return {"actors": dict(actors), "killed": killed, "bot_lines": bot_lines, "unknown": unknown}


def summary(r: dict, party: list[str]) -> str:
    out = []
    for name in party:
        a = r["actors"].get(name, _actor())
        parts = []
        if a["damage_done"]:
            parts.append(f"{a['damage_done']} damage")
        if a["healing_done"]:
            parts.append(f"healed {a['healing_done']}")
        if a["casts"]:
            parts.append("casts " + ", ".join(f"{s} x{n}" for s, n in sorted(a["casts"].items())))
        if a["deaths"]:
            parts.append(f"died {a['deaths']}x")
        out.append(f"{name}: " + ("; ".join(parts) if parts else "did nothing in the combat log"))
    out.append(f"Killed: {', '.join(r['killed']) or 'nothing'}. Unparsed lines: {r['unknown']}.")
    return "\n".join(out)
```

```python
# wowharness/server.py
"""GM commands over the core's SOAP interface; the server log over ssh."""
import re
import subprocess
from xml.sax.saxutils import escape

import requests

ENVELOPE = (
    '<?xml version="1.0" encoding="utf-8"?>'
    '<SOAP-ENV:Envelope xmlns:SOAP-ENV="http://schemas.xmlsoap.org/soap/envelope/" xmlns:ns1="urn:MaNGOS">'
    "<SOAP-ENV:Body><ns1:executeCommand><command>{cmd}</command></ns1:executeCommand></SOAP-ENV:Body>"
    "</SOAP-ENV:Envelope>"
)


class Server:
    def __init__(self, host, port, user, password, container, post=requests.post, run=subprocess.run):
        self.url, self.auth, self.container = f"http://{host}:{port}/", (user, password), container
        self._post, self._run = post, run

    def gm(self, cmd: str) -> str:
        body = ENVELOPE.format(cmd=escape(cmd)).encode("utf-8")
        try:
            r = self._post(self.url, data=body, auth=self.auth, headers={"Content-Type": "text/xml"}, timeout=15)
        except requests.RequestException as err:
            return f"SOAP error: {err}"
        if r.status_code != 200:
            m = re.search(r"<faultstring>(.*?)</faultstring>", r.text, re.S)
            return f"SOAP error: {m.group(1).strip() if m else r.text[:200]}"
        m = re.search(r"<result>(.*?)</result>", r.text, re.S)
        return m.group(1) if m else ""

    def log_since(self, seconds: int) -> str:
        p = self._run(["ssh", "gameserver", "docker", "logs", "--since", f"{seconds}s", self.container],
                      capture_output=True, text=True, timeout=30)
        return p.stdout + p.stderr
```

```lua
-- HarnessObserver.lua (WoW 1.12 API, Lua 5.0)
local function pct(cur, max) if not max or max == 0 then return 0 end return math.floor(cur * 100 / max) end
local function out(msg) DEFAULT_CHAT_FRAME:AddMessage(msg) end

function HX_Ready() out("HX|ready|" .. (UnitName("player") or "?")) end

function HX_State()
  local x, y = GetPlayerMapPosition("player")
  local s = "HX|p=" .. (UnitName("player") or "?") .. "," .. pct(UnitHealth("player"), UnitHealthMax("player"))
    .. "," .. pct(UnitMana("player"), UnitManaMax("player")) .. "," .. string.format("%.3f,%.3f", x or 0, y or 0)
    .. "," .. (GetRealZoneText() or "?")
  if UnitExists("target") then
    s = s .. "|t=" .. (UnitName("target") or "?") .. "," .. pct(UnitHealth("target"), UnitHealthMax("target"))
      .. "," .. (UnitIsDead("target") and "dead" or "alive")
  end
  local party = {}
  for i = 1, GetNumPartyMembers() do
    local u = "party" .. i
    table.insert(party, (UnitName(u) or "?") .. ":" .. pct(UnitHealth(u), UnitHealthMax(u)))
  end
  if table.getn(party) > 0 then s = s .. "|party=" .. table.concat(party, ",") end
  out(s)
end

local ticker, acc = CreateFrame("Frame"), 0
ticker:Hide()
ticker:SetScript("OnUpdate", function() acc = acc + arg1; if acc >= 1 then acc = 0; HX_State() end end)

SLASH_HX1 = "/hx"
SlashCmdList["HX"] = function(msg)
  if msg == "on" then ticker:Show() elseif msg == "off" then ticker:Hide() else HX_State() end
end
```

```python
# wowharness/mcp.py
"""The MCP tool surface. Run on Windows: python -m wowharness.mcp"""
import functools
import os
import time

from mcp.server.fastmcp import FastMCP

from .client import Client, ClientNotRunning
from .combat import parse_lines
from .config import load_config
from .report import build, summary

app = FastMCP("wowharness")
_state: dict = {}


def guarded(fn):
    @functools.wraps(fn)
    def run(*a, **k):
        try:
            return {"ok": True, **fn(*a, **k)}
        except ClientNotRunning as err:
            return {"ok": False, "error": str(err)}
    return run


def _client() -> Client:
    if "client" not in _state:
        from .window import Window
        cfg = load_config()
        exe = os.path.join(cfg.client_dir, "WoW.exe")
        _state["cfg"] = cfg
        _state["client"] = Client(cfg, lambda: Window.launch(exe, cfg.client_dir))
    return _state["client"]


def _server():
    if "server" not in _state:
        from .server import Server
        c = _state.get("cfg") or load_config()
        _state["server"] = Server(c.server_host, c.soap_port, c.soap_user, c.soap_password, c.server_container)
    return _state["server"]


@app.tool()
@guarded
def launch() -> dict:
    """Write Config.wtf (windowed, no movie, realmlist) and start WoW.exe."""
    return _client().launch()


@app.tool()
@guarded
def login(char_index: int = 0) -> dict:
    """Log the configured human account in and enter the world with the character at char_index."""
    c = _client()
    return c.login(c.cfg.account, c.cfg.password, char_index)


@app.tool()
@guarded
def chat(text: str) -> dict:
    """Type one line into the chat box (Enter, text, Enter)."""
    _client().chat(text); return {}


@app.tool()
@guarded
def run_lua(code: str) -> dict:
    """Run /script <code> in the client."""
    _client().run_lua(code); return {}


@app.tool()
@guarded
def key(name: str, hold_ms: int = 0) -> dict:
    """Press a key by name (w, a, s, d, space, enter, 1-9, f1-f12) for hold_ms."""
    _client().key(name, hold_ms); return {}


@app.tool()
@guarded
def screenshot() -> dict:
    """PNG of the WoW window; returns its Windows path."""
    c = _client(); c._check()
    path = os.path.join(os.path.expanduser("~"), "wowharness-shots", f"{int(time.time())}.png")
    os.makedirs(os.path.dirname(path), exist_ok=True)
    return {"path": c.window.screenshot(path)}


@app.tool()
@guarded
def state() -> dict:
    """One HX| state line from the observer addon."""
    c = _client(); since = c.chat_offset()
    c.chat("/hx")
    return {"line": c.wait_chat(r"HX\|p=", since, 10)}


@app.tool()
@guarded
def tail_combat_log(since: int = -1) -> dict:
    """Combat-log lines since a byte offset (-1 = just return the current offset)."""
    c = _client()
    if since < 0:
        return {"offset": c.combat_offset(), "lines": []}
    lines, off, restarted = c.combat_log.read_since(since)
    return {"offset": off, "lines": lines, "restarted": restarted}


@app.tool()
@guarded
def tail_chat(since: int = -1) -> dict:
    """Chat-log lines since a byte offset (-1 = just return the current offset)."""
    c = _client()
    if since < 0:
        return {"offset": c.chat_offset(), "lines": []}
    lines, off, restarted = c.chat_log.read_since(since)
    return {"offset": off, "lines": lines, "restarted": restarted}


@app.tool()
@guarded
def bot(cmd: str) -> dict:
    """Type a TortoiseBots player command: .bot <cmd>. Returns the TBM:/bot lines seen within 5 s."""
    c = _client(); since = c.chat_offset()
    c.chat(".bot " + cmd)
    time.sleep(5)
    lines, _, _ = c.chat_log.read_since(since)
    return {"lines": lines}


@app.tool()
def gm(cmd: str) -> dict:
    """A GM/console command over SOAP; the reply verbatim."""
    return {"ok": True, "reply": _server().gm(cmd)}


@app.tool()
@guarded
def fight_report(combat_since: int, chat_since: int, me: str, party: list[str]) -> dict:
    """Parse the fight since the given offsets: per-actor totals, bot lines, and a text summary."""
    c = _client()
    lines, _, _ = c.combat_log.read_since(combat_since)
    chat_lines, _, _ = c.chat_log.read_since(chat_since)
    rep = build(parse_lines(lines, me), chat_lines, me, party)
    return {"report": rep, "summary": summary(rep, party)}


if __name__ == "__main__":
    app.run()
```
